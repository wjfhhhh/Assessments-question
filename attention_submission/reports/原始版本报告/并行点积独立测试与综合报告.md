# 四路并行点积版独立测试报告

测试日期：2026-10-12。对照版本为未修改的 93 拍 AB 版 attention_ip_parallel；被测版本为 attention_ip_parallel_dot。

## 改动范围

仅优化 DOT 的四维点积数据通路：四个十六位有符号乘法结果，经十七位、十八位的两层加法树相加。取消旧的点积累加寄存器，每拍处理一个 Key；沿用因果 Mask、点积同步最大值、四路加权累加及原有归一化舍入。

输入接口和装载节拍不变，没有流水化或并行装载。DOT 的 score_valid 连续八拍为高，每拍代表一个不同 Score。

## 独立仿真结果

使用 Icarus Verilog 13.0，从本目录 scripts/run_tests.ps1 实际运行。1076 组案例分别执行对照验证和快速连续任务两种模式，均通过，退出码均为零。

```text
PASS: 1076 cases, 8608 scores, 8608 weights, 4304 outputs, 2074793 division inputs
CYCLES: AB=57 DOT=33 after final KV; savings=24; AB/DOT results matched for all cases
```

第二遍不等待旧 AB 完成，继续启动新任务，仍与独立数学模型核对。两遍使用同一组案例，不计为 2152 个不同案例。

另对 130561 个整数差值进行指数 LUT 检查。覆盖全部查询位置与 Mask 开关、小范围/全范围随机值、极值、全负分数、未来位置扰动、配置锁存、输入暂停、忙碌 start、各阶段中途复位及无复位连续任务。

特别包含四个乘法分支分别处理 −128×−128、−128×127，以及四项 16384 相加得到 65536 的案例，检查每级符号扩展和溢出边界。沿用第四项改变最大值、最后合法项最大等定向案例。

测试逐拍检查 Score、合法前缀最大值、权重、L、四路 ACC、输出及 done。不只是比较最终输出。详细案例信息见 results/coverage.json，编译/仿真状态及源码哈希见 results/validation.json。

## 周期

以最后 K/V 接收为第零拍，DOT 为 1～8，EXP 为 9～16，UPDATE 为 17～24，NORM 为 25～28，OUTPUT 为 29～32，done 为 33。

无停顿 start→done 由 93 拍降至 69 拍，减少 24 拍，约 25.8%；DOT 本身由 32 拍降至 8 拍。输入暂停会延长完整任务时间，但不改变收齐输入后的 33 拍。

## 同条件综合结果

Vivado 2022.2，器件 xc7z010iclg225-1L，综合前加载 10 ns 时钟约束，两个版本均以 out-of-context 方式重新综合。

| 指标 | 旧 AB：串行点积 | 新版：四路并行点积 |
|---|---:|---:|
| Slice LUTs | 853 | 1069 |
| Slice Registers | 879 | 863 |
| DSP | 0 | 0 |
| Block RAM Tile | 0 | 0 |
| 锁存器 | 0 | 0 |
| 综合后 WNS | −21.344 ns | −21.337 ns |

LUT 增加 216 个，约 25.3%；FF 减少 16 个，涉及去掉串行点积累加寄存器以及综合优化。乘法映射到 LUT，没有增加 DSP。原始报告在 evidence/synthesis_OLD 和 evidence/synthesis_DOT。

两版均未满足 10 ns 约束。新版最差路径从 acc_raw_reg[1][14] 到 output_mem_reg[0][7]，仍经过组合归一化除法，数据路径延迟 31.315 ns。0.007 ns 的综合裕量差异不能据此宣称实际频率提升。

本机初次尝试因隔离运行库内容不完整而未启动；随后从本机已安装 Vivado 准备了新的隔离运行库，未修改安装目录。重新运行后两版综合报告均已生成，但 Vivado 仍以访问异常退出。evidence/synthesis_status.json 记录 reports_completed=true、退出码 −1073741819；脚本如实报错。
