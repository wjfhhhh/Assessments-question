## 如何重跑

在 PowerShell 执行：

```powershell
& 'D:\VivadoProject\attention_demo\defense_mask\independent_tests\scripts\run_tests.ps1' -Python 'C:\Users\admin\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
```

脚本默认使用本机已经安装的便携 Icarus。换电脑需准备 Python 与 Icarus，并通过 -Python、-IcarusBin 指定路径。
预期答案由参考模型当场生成，无需手工填写。

## 覆盖的风险

- 查询位置零至七以及 Mask 开关两种模式。
- 全负合法分数、重复最大值、未来位置包含比分数最大值更大的数、八位输入极值。
- 八对仅修改未来 K/V 的输入，合法权重和输出保持不变。
- 关闭 Mask 或查询位置为七时，与基础模块同拍比对输出和接口。
- 在 start 后改变外部配置，检查本次计算仍使用锁存配置。
- 输入暂停、忙碌期间 start、多个计算阶段中途复位、任务之间不复位。
- 四位小数指数、正负舍入和除零防御。

## 可手算的第一组自检

```text
Mask 开启，位置二
Score      = [3,2,1,0,-1,3,2,1]
合法最大值 = 3
Weight_raw = [16,6,2,0,0,0,0,0]
L_raw      = 24
ACC_raw    = [34,68,-34,136]
输出       = [1,3,-1,6]
```

现场演示使用了未来分数更大的另一组输入，便于对比开关。其实际日志保存为 results/vivado_mask.log。
其中开启位置二得到 [1,3,-1,6]，关闭得到 [100,20,-100,-20]，开启位置零得到 [1,2,-1,4]。
两套输入不同属于正常情况，不能把某套日志当作另一套的波形证据。
